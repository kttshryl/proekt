# устав проекта

## 1. общие сведения о проекте

| поле | значение |
|---|---|
| название проекта | последняя электричка |
| тип продукта | текстовая интерактивная новелла с развилкой и несколькими концовками |
| учебная группа |  12тэс |
| формат работы | команда из 4 человек |
| срок проекта | 2 дня (3 этапа: v0.1, v0.2, v1.0) |
| дата старта | 26 ноября 2026 |
| дата защиты | 27 ноября 2026 |

## 2. идея проекта

создать короткую текстовую новеллу, в которой игрок играет за студента сашу. саша поздним вечером остался на незнакомом полустанке: следующая электричка только утром, телефон почти разряжен, в кармане 200 рублей. игрок выбирает, как добраться домой: рискнуть остановить поезд не по расписанию, поискать ночлег рядом со станцией или дождаться утренней электрички.

каждый выбор меняет дальнейшие события и приводит к одной из четырёх концовок:
- «дом, милый дом» — приключение с хорошим концом;
- «ночь на вокзале» — плохая концовка концовка;
- «спокойный путь» — спокойная концовка.

## 3. цель проекта

сделать рабочий прототип новеллы с тремя сохранёнными версиями (v0.1, v0.2, v1.0), не менее чем пятью функциями, документацией и презентацией.

## 4. задачи проекта

1. придумать короткий сюжет с тремя развилками и четырьмя концовками.
2. собрать прототип v0.1 с одной проходимой сценой.
3. добавить функции до пяти и выпустить версию v0.2.
5. исправить найденный дефект и выпустить финальную версию v1.0.
6. заполнить документацию и отчёт о тестировании.
7. подготовить презентацию на 7 слайдов и выступить на защите.

## 5. для кого предназначен продукт

| аудитория | чем продукт полезен или интересен |
|---|---|
| студенты и школьники | короткая история о знакомой ситуации — поздняя дорога домой, ограниченные деньги, усталость; проходится за 5–10 минут |
| начинающие игроки в новеллы | простой интерфейс, понятные кнопки, небольшое количество выборов, не нужно устанавливать игру |
| учебные команды | готовый пример проекта с тремя версиями, документацией и тестированием, по которому можно учиться оформлять свой проект |

## 6. почему проект интересен аудитории

- тема поздней дороги и ограниченных денег близка студентам, история вызывает узнавание.
- короткое прохождение (1-2 минуты) не требует много времени.
- четыре концовки вызывают желание переиграть и проверить другие варианты.
- выбор игрока реально меняет события, а не просто меняет текст на экране.

## 8. результат проекта

- три сохранённые версии новеллы: v0.1, v0.2, v1.0 — отдельными папками.
- пять работающих функций: начать игру, перейти к следующей реплике, выбрать ответ, получить концовку по выбору, открыть экран итога.
- документация в markdown: устав, план, требования, тз, протокол встречи, отчёт о статусе, документация продукта.
- отчёт о тестировании с ожидаемым и фактическим результатами, доработкой и повторными проверками.
- презентация на 7 слайдов со скриншотами «до / после».

## 9. ограничения и допущения

- история короткая: одна основная линия с тремя развилками.
- для запуска достаточно скачать python. программу можно открыть в любом редакторе (Visual Studio Code, PyCharm..)
